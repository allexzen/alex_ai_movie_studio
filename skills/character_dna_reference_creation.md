# Skill: Character DNA Reference Creation

## Purpose

Create a complete character reference package from a single source image.

The goal is to generate a stable "character DNA" sheet that can later be used for:
- AI video generation
- cinematic scenes
- motion transfer
- talking characters
- consistent multi-angle rendering

This skill focuses on identity preservation and multi-view consistency.

---

# Core Principle

The provided image is the canonical identity source.

All generated reference views must represent:
- the SAME person
- the SAME face structure
- the SAME body proportions
- the SAME identity

NOT variations or reinterpretations.

---

# Required Output

Generate a full character turnaround/reference sheet including:

- front view
- left profile
- right profile
- 3/4 front view
- 3/4 back view
- full body front
- full body side
- neutral expression
- optional emotion variations

All views must maintain strict consistency.

---

# Identity Lock Rules

Preserve:

- face shape
- jawline
- eyes
- nose
- lips
- hairstyle silhouette
- body proportions
- age appearance
- skin tone
- defining details

Do NOT:
- beautify
- stylize excessively
- randomize features
- change ethnicity appearance
- alter gender presentation

---

# Generation Style

Preferred output style:

- neutral lighting
- studio lighting
- clean background
- reference-sheet format
- highly readable details
- minimal cinematic effects

Goal:
maximum consistency, not artistic beauty.

---

# Camera Rules

Use:
- orthographic-like views when possible
- centered framing
- proportional alignment

Avoid:
- dramatic angles
- wide lens distortion
- heavy perspective distortion
- cinematic motion blur

---

# Clothing Rules

Prefer:
- simple neutral clothing
- form-visible silhouette
- minimal accessories

Reason:
clothing must not hide body proportions.

---

# Hair Rules

Hair must remain:
- structurally consistent
- shape-consistent
- volume-consistent

Minor movement allowed.
Identity drift not allowed.

---

# Video Pipeline Compatibility

This reference sheet should later support:
- Kling
- Veo
- Runway
- Hailuo
- character consistency workflows
- motion transfer systems

The output should function as:
a reusable AI actor identity base.

---

# Prompt Behavior

When generating reference sheets:

Prioritize:
1. consistency
2. anatomical stability
3. recognizability

NOT:
- cinematic beauty
- artistic reinterpretation
- fashion stylization

---

# Output Goal

Create a reusable "character DNA package"
that can serve as the canonical source
for future AI video generation.
